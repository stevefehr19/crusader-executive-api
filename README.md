# Crusader Public Executive API

Sanitized, read-only static JSON for ordinary public retrieval clients. The local Crusader control planes remain canonical; this publication is a copy and never a write surface.

## Required feeds

- <https://stevefehr19.github.io/crusader-executive-api/api/ping.json>
- <https://stevefehr19.github.io/crusader-executive-api/api/index.json>
- <https://stevefehr19.github.io/crusader-executive-api/api/officers/commander.json>
- <https://stevefehr19.github.io/crusader-executive-api/api/officers/cso.json>
- <https://stevefehr19.github.io/crusader-executive-api/api/officers/trading-director.json>

Every state document includes `generated_at`. If that timestamp is old, describe the public copy as stale rather than presenting it as current.

Publication is GET-only and generated by the existing allow-list publisher. Credentials, tokens, private reports, client data, private trading evidence, and control-plane databases are excluded.
