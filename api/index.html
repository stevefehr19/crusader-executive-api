Crusader Public Executive API

Read-only JSON projections of current Crusader state, generated from the local Crusader Command Center. GET only — there is no write method and no query string, and every discovery slice is pre-computed. The local control planes remain canonical; this is a sanitized projection and never the source of truth.

Every document carries generated_at and updated_at. If generated_at is old, this is a stale copy — say so rather than presenting it as current.
